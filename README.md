# LincsDirectory

Source for [lincsdirectory.co.uk](https://lincsdirectory.co.uk/), the Lincolnshire local directory from TAG Sleaford Ltd: a static site published with GitHub Pages. Listings are built from public data (Food Standards Agency FHRS data under the Open Government Licence v3.0, and OpenStreetMap contributors, ODbL); businesses can claim, correct or remove their listing free at any time from the site. Questions: hello@lincsdirectory.co.uk.
