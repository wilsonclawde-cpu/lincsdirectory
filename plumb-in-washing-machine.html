Plumb in a washing machine: the basics

What the job involves

Connecting a washing machine means fitting the cold (and sometimes hot) supply hose to a valve, connecting the waste hose to a standpipe or the sink waste, levelling the machine and running a test cycle. If there is no existing connection point a plumber will add a valve on the nearest cold pipe and a waste connection, which takes longer.

What to ask a pro, and what to have ready

Tell the plumber whether there is already a washing machine point, how far it is from the sink, and whether the machine is new (transit bolts need removing) or being moved from another room. Ask whether the price covers new hoses and a valve, taking the old machine away, and the first test run.

Safety and good to know

A washing machine needs its own socket, not an extension lead, and the waste hose needs a proper connection with a high loop so dirty water can't siphon back. About plumb in a washing machine

Do I need a plumber to fit a washing machine?

If there is already a cold valve and a waste point, it is a simple job that many people do themselves. A plumber is worth it when there is no connection point, the old valve is seized, or the machine is going somewhere new.
